# Warehouse Simulator — V0.8

Статическая браузерная management-игра для портфолио.

## Запуск

Открой `index.html` в браузере. Для GitHub Pages достаточно положить папку `warehouse-simulator` рядом с остальными проектами сайта.

Кнопка возврата сейчас использует относительный путь `../index.html`.

## Что уже есть

- пять процессов: Receiving → Putaway → Picking → Packing → Shipping;
- FIFO-поток, возраст заказов, четыре ограниченных буфера и backpressure;
- Worker / Trainee, найм, обучение, увольнение и перераспределение;
- экономика, upgrades зон, буферов и три общескладских улучшения;
- SLA, recovery window и Warehouse Shutdown;
- Pause / ×1 / ×2 / ×4;
- Normal Shift, Black Friday и Endless;
- 38 событий: 11 Information, 12 Problem, 15 Decision;
- условия, веса и cooldown событий;
- активные временные эффекты с таймерами;
- стилизованный визуальный склад: ворота, машины, стеллажи, тележки, упаковка, условные работники и очереди;
- RU / EN;
- `? Как играть`, tooltips и подсказки первого запуска;
- необязательный звук, выключенный по умолчанию;
- итоговая оценка смены и компактные графики SLA / входящего потока;
- лучший Endless score через localStorage.

## Где менять баланс

Основные стартовые параметры сценариев находятся в `scenarios.js`.

События, их `weight`, `cooldown`, `minTime`, `condition`, эффекты и варианты решений находятся в `events.js`.

Пользовательские тексты RU / EN находятся в `translations.js`.

## Принцип

Простая математическая модель под капотом — живой склад на экране.
