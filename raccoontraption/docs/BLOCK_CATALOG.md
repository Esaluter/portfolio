# Каталог блоков

В интерфейсе блоки сгруппированы по назначению: **Core** — Number и Output, **Math** — Math и Random, **Logic** — Compare и Logic, **Visual** — Indicator. Клик по элементу сворачиваемого левого каталога создаёт блок на ближайшей свободной позиции canvas.

Все значения графа имеют тип `number` или `boolean`. Соединение разрешается только при совместимых типах портов; Output и Indicator принимают оба типа.

При сохранении записываются только редактируемые параметры, перечисленные для каждого блока ниже. Вычисленные значения, ошибки и callbacks не входят в JSON. После импорта вычисляемые значения очищены до следующего нажатия «Запустить».

## Number (Число)

**Назначение.** Источник числа.

**Параметры.** `value`, начальное значение `0`.

**Порты.** Входов нет; один числовой выход.

**Поведение.** Возвращает конечное число. `NaN` и бесконечность дают контролируемую ошибку.

**Пример.** Два Number можно подать в Math/Add.

## Random (Случайное число)

**Назначение.** Генерирует случайное целое число.

**Параметры.** `Min = 1`, `Max = 100`.

**Порты.** Входов нет; один числовой выход.

**Поведение.** При каждом Run генерирует целое число из замкнутого диапазона `[Min, Max]`. В пределах одного запуска значение кэшируется и одинаково для всех потребителей.

**Ограничения.** Обе границы должны быть конечными целыми числами, `Min ≤ Max`. Некорректный диапазон даёт ошибку `invalid-random-range`. Два запуска могут случайно вернуть одно число.

**Пример.** `Random(1..6) → Output` имитирует бросок кубика.

## Math (Математика)

**Назначение.** Выполняет арифметику над числами.

**Параметры.** Сложение, вычитание, умножение или деление; начальная операция — сложение.

**Порты.** Один числовой вход `input`, допускающий несколько связей; числовой выход `result`.

**Поведение.** Все источники вычисляются рекурсивно. Ошибка или пустое значение подключённого источника распространяется в Math. Без связей результат пустой.

**Ограничения.** Порядок вычитания и деления задаётся порядком связей, а не именованными операндами. Деление на ноль и неконечный результат становятся ошибками.

**Пример.** `Number(10), Number(2) → Math/Divide → Output` даёт 5 при соответствующем порядке связей.

## Compare (Сравнение)

**Назначение.** Сравнивает два числа и возвращает boolean.

**Параметры.** `>`, `<`, `>=`, `<=`, `==`, `!=`; начальная операция — `>`.

**Порты.** Именованные числовые входы A и B, максимум по одной связи; boolean-выход `result`.

**Интерфейс.** Выбор операции, строки входов A/B, результат и выход разделены визуально; подписанные порты расположены напротив соответствующих строк.

**Поведение.** Порядок операндов задают handles A/B, а не порядок связей. Сравнение строгое, без преобразования типов. При отсутствии обязательного входа результат пустой.

**Ограничения.** Источник с ошибкой создаёт ошибку зависимости. Boolean-источник подключить нельзя.

**Пример.** `Number(10) → A`, `Number(5) → B`, `Compare(>) → Output` показывает `true`.

## Logic (Логика)

**Назначение.** Выполняет AND, OR, NOT или XOR над boolean.

**Параметры.** Начальная операция — AND.

**Порты.** Boolean-вход A; для AND, OR и XOR также boolean-вход B. Каждый принимает максимум одну связь. Выход `result` имеет тип boolean.

**Интерфейс.** Выбор операции, входы, результат и выход находятся в отдельных областях. В режиме NOT строка и порт B скрыты, а геометрия оставшихся портов пересчитывается React Flow.

**Поведение.** Двухвходовые операции проверяют обе зависимости без short-circuit. NOT использует только A. Пустой обязательный вход оставляет результат пустым.

**Переключение на NOT.** Если к B была подключена связь, она удаляется вместе со сменой операции как одно Undo/Redo-действие. При выборе AND, OR или XOR порт B возвращается.

**Ограничения.** Числовой источник подключить нельзя. Ошибки зависимостей распространяются дальше.

**Пример.** Результаты двух Compare можно соединить с Logic/AND и затем с Output.

## Output (Вывод)

**Назначение.** Показывает итоговое значение.

**Параметры.** Нет.

**Порты.** Один вход для `number | boolean`, максимум одна связь; выходов нет.

**Поведение.** Показывает число, `true`, `false` или `—`. Ошибка источника отображается вместо значения.

**Ограничения.** Не объединяет несколько источников.

**Пример.** Принимает результат Math, Random, Compare или Logic.

## Indicator (Индикатор)

**Назначение.** Показывает число или boolean в визуальной форме внутри блока и на панели Preview.

**Параметры.** `label` длиной до 60 символов; режим AUTO, STATUS или GAUGE; конечный диапазон `Min < Max`, по умолчанию 0–100.

**Порты.** Один универсальный вход `value`, максимум одна связь; выходов нет.

**Поведение.** AUTO отображает boolean как зелёный/красный статус, а number как горизонтальную шкалу. STATUS принимает только boolean. GAUGE принимает только number, показывает исходное число и ограничивает заполнение шкалы диапазоном 0–100%. Без доступного значения отображается «Енот ждёт сигнал».

**Ошибки.** Несовместимость режима и типа, некорректный диапазон и ошибка источника дают контролируемую ошибку с доступной технической причиной.

**Сохранение.** JSON v1 хранит `label`, `mode`, `min` и `max`, но не вычисленное значение, ошибку или состояние Preview.

**Пример.** `Random → Indicator/GAUGE` показывает число и шкалу; `Compare → Indicator/STATUS` показывает решение енота.
