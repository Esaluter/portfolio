# Журнал разработки Raccoontraption

Журнал разработки Raccoontraption. Здесь фиксируются завершённые и проверенные изменения проекта по дням.

## 17.10.2026

- Технически завершён Playground UX + Demo Gallery: верхняя панель действий, сворачиваемый каталог слева, основной React Flow canvas и сворачиваемый Preview справа собраны в единое рабочее пространство.
- Семь блоков сгруппированы в Core, Math, Logic и Visual; каталог использует прежние фабрики и поиск свободной позиции. Пустой canvas показывает приглашение с действиями «Открыть примеры» и «Добавить число».
- Добавлена модальная галерея с четырьмя примерами: «Кубик судьбы», «Детектор удачи», «Логическая лаборатория» и «Машина вычислений». Диалог закрывается по Escape, блокирует горячие клавиши редактора и требует подтверждения перед заменой непустого графа.
- Примеры хранятся как обычные `SavedGraphV1` и проходят существующий `deserializeGraph`. Успешная загрузка очищает runtime-результаты, не выполняет Run, записывается одним действием Undo/Redo и после обновления вызывает React Flow `fitView`; ошибка не меняет граф.
- Тёмная тема получила единую системную типографику, кнопки, input/select, состояния hover/focus/disabled и десктопную адаптивность; размеры и слои handles не изменялись.
- Добавлено 15 автоматических тестов определений примеров, параметров, связей, persistence, чистого состояния, повторной загрузки, отсутствия мутаций и атомарной ошибки; полный набор расширен со 125 до 140 тестов в пяти файлах.
- `npm run lint`, `npm run build` и `npm run test` выполнены успешно; 140 тестов прошли.
- Локальная браузерная проверка подтвердила пустое состояние, четыре карточки галереи, отсутствие автоматического Run, подтверждение замены, блокировку Delete за модальным окном, закрытие по Escape, Run и Preview, Undo/Redo примера, освобождение canvas при сворачивании панелей и отсутствие ошибок консоли. На ширинах 1920, 1440, 1280 и 1024 px canvas сохраняет рабочую область; при 1024 px действия доступны через предусмотренную горизонтальную прокрутку. Ручная приёмка пользователем ожидается.

- Технически завершён Visual Preview v1: добавлены конечный блок Indicator и сворачиваемая правая панель Preview в существующем тёмном стиле.
- Indicator принимает один `number | boolean` на входе `value`, не имеет выхода и поддерживает AUTO, STATUS и GAUGE, подпись до 60 символов и конечный диапазон `Min < Max`.
- Engine получает исходное значение без преобразования типов, проверяет диапазон и режим, распространяет ошибки зависимости и оставляет неподключённый Indicator пустым. Визуальная модель STATUS/GAUGE/EMPTY/ERROR вынесена в отдельную чистую функцию.
- Preview показывает все Indicator из актуального графа, использует ту же визуальную модель, обновляется после Run и не запускает вычисления самостоятельно.
- После смыслового редактирования узлов или связей вычисляемые значения и старые ошибки очищаются до следующего Run; браузерная проверка подтвердила исчезновение шкалы после изменения Number без повторного запуска.
- Indicator добавлен в типизированные правила соединений и persistence JSON v1. Старые документы v1 без Indicator продолжают импортироваться; runtime-значение, ошибки, callbacks и состояние Preview не сохраняются.
- Добавлен 31 автоматический тест engine, соединений, представлений, очистки устаревшего состояния и persistence; полный набор расширен с 94 до 125 тестов в четырёх файлах.
- `npm run lint`, `npm run build` и `npm run test` выполнены успешно; 125 тестов прошли.
- Локальная браузерная проверка подтвердила создание и соединение Number → Indicator, числовой AUTO/GAUGE, синхронизацию блока и Preview, очистку устаревшего результата и сворачивание панели. Ручная приёмка пользователем ожидается.

- Технически завершён этап C: добавлены экспорт в `raccoontraption.json` и атомарный импорт формата `raccoontraption` версии 1.
- Сериализация явно сохраняет только ID, типы, позиции, редактируемые параметры и связи с handles; callbacks, ошибки, выделение и временные вычисленные результаты исключены.
- Импорт проверяет размер файла, структуру, версию, шесть допустимых типов блоков, уникальность ID, координаты, параметры, существование узлов, handles, совместимость типов, занятость входов и дублирующиеся связи. Структурно допустимые циклы разрешены.
- Невалидный импорт не меняет текущий граф. Успешный импорт очищает runtime-результаты и ошибки, не запускает вычисление и записывается одним действием Undo/Redo.
- Генерация ID усилена временем, монотонным счётчиком и проверкой занятых ID, чтобы новые элементы не конфликтовали с импортированными.
- Добавлен 21 тест persistence-слоя; полный набор расширен с 73 до 94 тестов в трёх файлах.
- `npm run lint`, `npm run build` и `npm run test` для этапа C выполнены успешно; 94 теста прошли.
- Ручной smoke-test импорта и скачивания файла ожидает подтверждения пользователя; этап C не отмечен принятым.

- Ручная приёмка этапа B выявила перекрытия элементов Compare/Logic, недостаточно заметные и труднодоступные порты Logic и частично английские подписи кнопок создания блоков.
- Причиной проблем компоновки были абсолютные координаты подписей и handles поверх содержимого переменной высоты. Дополнительно Logic менял набор handles при выборе NOT без явного пересчёта внутренних размеров React Flow, а стандартные маленькие handles имели слабую визуальную и интерактивную доступность.
- Compare и Logic переведены на общую строку `PortRow` и отдельные области операции, входов, результата, выхода и ошибки. Порты увеличены, визуально выделены и выровнены с подписями; длинные сообщения ошибок переносятся внутри блока.
- Logic вызывает `useUpdateNodeInternals` при появлении или исчезновении входа B. Проверка типов не ослаблялась: Compare → Logic, Logic → Logic и Logic → Output разрешаются по прежним типизированным правилам, а несовместимые Number → Logic и Logic → Math отклоняются.
- Кнопки создания новых блоков локализованы как «Случайное», «Сравнение» и «Логика».
- Добавлены пять регрессионных тестов соединений Logic; полный набор расширен с 68 до 73 тестов.
