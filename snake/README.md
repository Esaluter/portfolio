# Snake

Небольшая браузерная реализация классической игры «Змейка», созданная как отдельный проект для раздела **Laboratory** моего портфолио.

Цель проекта — сделать простую и законченную мини-игру без лишнего усложнения: с классической механикой, аккуратным интерфейсом, локальными рекордами и небольшим изменением привычных правил.

## Особенность

В этой версии столкновение с границей игрового поля **не заканчивает игру**.

Змейка переходит на противоположную сторону:

* справа → налево;
* слева → направо;
* сверху → вниз;
* снизу → вверх.

Игра заканчивается только при столкновении змейки с собственным телом.

## Возможности

* управление через **WASD** и **стрелки**;
* пауза и продолжение игры через **Space** или кнопку интерфейса;
* постепенное увеличение скорости;
* текущий счёт и лучший результат;
* локальная таблица **TOP-10**;
* сохранение имени игрока и результата;
* сохранение рекордов через `localStorage`;
* русский и английский интерфейс;
* сохранение выбранного языка;
* запуск новой игры без перезагрузки страницы;
* переход обратно в основное портфолио.

## Технологии

* HTML
* CSS
* Vanilla JavaScript
* Canvas API
* localStorage

Проект работает полностью на стороне браузера и не использует backend, базы данных, фреймворки, npm или внешние зависимости.

## О проекте

Snake — один из небольших экспериментальных проектов моего портфолио.

Основная идея Laboratory — пробовать новые инструменты и технологии, превращать небольшие идеи в работающие проекты и учиться через практику.
