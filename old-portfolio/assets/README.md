# Assets

- `map/` — базовая иллюстрация мира;
- `locations/` — отдельные графические ассеты локаций;
- `player/` — персонаж;
- `audio/` — зарезервировано под будущие аудиофайлы; V1.0 использует процедурный Web Audio API.

Необязательный location/player-ассет не должен полностью ломать карту. Базовая карта считается критическим визуальным ресурсом: при её отсутствии включается fallback-навигация.
