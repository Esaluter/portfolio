# Raccoontraption

Raccoontraption — визуальная песочница, в которой конструкции собираются из соединяемых блоков: пользователь добавляет блоки на canvas, связывает их, задаёт параметры и запускает вычисление.

Сейчас проект находится на стадии MVP. В нём можно собирать числовые и логические цепочки из семи типов блоков и выводить результаты в визуальный Preview. Режимы PLAY, REMIX и BUILD относятся к продуктовому направлению и пока не реализованы.

## Стек

- React 19 и TypeScript;
- Vite 8;
- React Flow (`@xyflow/react`) для узлов, связей и canvas;
- ESLint.

## Что уже работает

- добавление блоков Number, Random, Math, Compare, Logic, Output и Indicator;
- трёхзонный редактор с каталогом блоков слева, canvas по центру и Preview справа;
- сворачиваемый каталог с категориями Core, Math, Logic и Visual;
- галерея из четырёх готовых экспериментов и приглашение на пустом canvas;
- автоматическое размещение новых блоков на свободных позициях;
- соединение блоков направленными связями;
- операции сложения, вычитания, умножения и деления;
- генерация случайных целых чисел в диапазоне;
- шесть операций сравнения и логические AND, OR, NOT, XOR;
- значения типов `number` и `boolean` без неявных преобразований;
- цепочки вычислений `Math → Math`;
- смешанные цепочки `Math → Compare → Logic → Output`;
- запуск вычисления кнопкой «Запустить»;
- Indicator в режимах AUTO, STATUS и GAUGE;
- сворачиваемая панель Preview со всеми Indicator текущего графа;
- очистка устаревших результатов после смыслового редактирования до следующего Run;
- отдельный тестируемый execution engine;
- обнаружение циклов, деления на ноль и некорректных чисел;
- распространение ошибок по зависимой цепочке и их отображение в блоках;
- независимое вычисление исправных ветвей графа;
- не более одной входящей связи для Output;
- типовая проверка соединений и именованные входы A/B;
- выбор и удаление блоков и связей;
- Undo/Redo, включая `Ctrl/Cmd+Z`, `Ctrl/Cmd+Y` и `Ctrl/Cmd+Shift+Z`;
- экспорт конструкции кнопкой «💾 Сохранить» в версионированный JSON-файл;
- атомарный импорт кнопкой «📂 Загрузить» с проверкой блоков, параметров, портов и связей;
- перемещение и масштабирование canvas средствами React Flow.

Ограничения вычислений и интерфейса перечислены в [описании архитектуры](docs/ARCHITECTURE.md#известные-ограничения).

## Требования

- Node.js `^20.19.0` или `>=22.12.0` (требование установленной версии Vite);
- npm.

## Установка и запуск

```bash
npm install
npm run dev
```

Vite выведет локальный адрес приложения в терминале.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запустить сервер разработки с HMR |
| `npm run build` | Проверить TypeScript и собрать production-версию |
| `npm run lint` | Запустить ESLint |
| `npm run test` | Один раз запустить автоматические тесты Vitest |
| `npm run preview` | Локально открыть ранее собранную production-версию |

Автоматические тесты покрывают execution engine, все семь блоков, Preview-представление, правила соединений, persistence и пользовательские сообщения ошибок.

## Сохранение конструкции

Кнопка «💾 Сохранить» скачивает `raccoontraption.json`. Файл содержит версию формата, ID и позиции блоков, редактируемые параметры и связи с идентификаторами портов. Вычисленные результаты, ошибки, выделение и React callbacks не сохраняются.

Кнопка «📂 Загрузить» открывает стандартный выбор файла. Импорт полностью проверяется до замены текущего графа, не запускает вычисление автоматически и записывается одним действием Undo/Redo. Поддерживается формат `raccoontraption`, версия `1`; максимальный размер файла — 1 000 000 байт, до 1 000 блоков и 5 000 связей.

Indicator сохраняется в том же формате JSON v1 с параметрами `label`, `mode`, `min` и `max`. Старые файлы v1 без Indicator продолжают загружаться.

## Галерея примеров

Кнопка «🧪 Примеры» открывает четыре обычных редактируемых графа: «Кубик судьбы», «Детектор удачи», «Логическая лаборатория» и «Машина вычислений». Они проходят тот же JSON v1-валидатор, что и пользовательский импорт. Загрузка не выполняет Run, очищает вычисленные результаты и попадает в историю одним действием; Undo возвращает прежнюю конструкцию, Redo снова применяет пример. Для непустого canvas требуется явное подтверждение замены.
