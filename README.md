# Evgeny • Portfolio & Experiments — V1.0

Интерактивная главная страница-портфолио в виде небольшой рисованной карты-путешествия.

## Что входит в V1.0

- цельная desktop-карта 1600×900 с адаптивным масштабированием;
- персонаж-путешественник;
- WASD / стрелки и click-to-move;
- A* pathfinding и коллизии;
- естественные границы мира: вода, горы, скалы и препятствия;
- пять основных локаций: Analytics, About Me, GitHub, Contacts, Laboratory;
- взаимодействие через E / Enter и автоматическое открытие после клика по локации;
- Loading, Intro, HUD, Menu и fallback-навигация;
- русский и английский интерфейс;
- процедурный звук через Web Audio API, выключенный по умолчанию;
- фоновые эффекты живого мира: вода, дым, туман, огни;
- возврат на карту к последней локации;
- сохранение языка и состояния звука в пределах текущего посещения.

## Запуск локально

Открой `index.html` в браузере. Для публикации проект рассчитан на статический хостинг, включая GitHub Pages.

## Перед публикацией

1. В `js/config.js` замени `github: "https://github.com/"` на свою ссылку.
2. Если будешь менять адреса внутренних разделов, они лежат в `js/world.js` в `action.href` у Analytics / About / Contacts / Laboratory.
3. Проверь опубликованную версию в Chrome / Edge / Firefox.

## Структура

- `index.html` — главная карта;
- `css/` — интерфейс;
- `js/config.js` — настройки, ссылки и параметры;
- `js/world.js` — геометрия мира, локации, коллизии и зоны;
- `js/pathfinding.js` — навигация;
- `js/game.js` — движение, взаимодействие, рендер и состояния;
- `js/audio.js` — процедурный звук;
- `js/i18n.js` — RU / EN;
- `assets/` — карта и графические ассеты;
- `pages/` — внутренние точки перехода.

V1.0 сознательно остаётся простой: HTML + CSS + JavaScript, без тяжёлого игрового движка и без лишних зависимостей.
