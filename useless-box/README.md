# The Most Useless Box — V0.9

Небольшой интерактивный браузерный эксперимент для персонального портфолио.

Пользователь включает тумблер. Коробка открывается, механический манипулятор выходит из внутренней полости, выключает тумблер и возвращается обратно.

Главное техническое решение V0.9: **базовая механика коробки собрана из HTML/CSS**, а не из отдельных PNG-слоёв. Это специально устраняет проблемы старого прототипа: съезжающий тумблер, несовпадающие перспективы и полностью «вылетающий» манипулятор.

## Запуск

Просто открой `index.html`.

Никакого сервера, npm или сборки не требуется.

## Архитектура сцены

### Неподвижные элементы

- `.box-body`
- `.front-panel`
- `.cavity`
- `.cavity-lip`
- `.switch-plate`

### Подвижные элементы

- `.lid`
- `.switch-lever`
- `.arm`

Все элементы находятся внутри одного `.scene`, поэтому desktop и mobile используют одну геометрию.

### Почему переключатель сделан CSS

OFF/ON, металлическая площадка, socket и lever находятся в одной DOM-структуре. Отдельный PNG рычага больше не нужен, поэтому рычаг не может «съехать» относительно площадки.

### Почему манипулятор сделан CSS

Манипулятор состоит из вложенных сегментов. Его корневая точка находится внутри `.cavity`. Меняются общий scale, shoulder angle, elbow angle и wrist angle. Основание не перемещается к тумблеру — двигается кинематическая цепочка.

## Animation primitives

В `script.js` используются общие primitives:

- `openLid()`
- `closeLid()`
- `pose()`
- `switchOff()`
- `showMessage()`
- `fx()`

Реакции описываются последовательностями действий, а не отдельными анимационными движками.

### Как добавить реакцию

Добавь новый объект в массив `reactions`:

```js
{
  id: "myReaction",
  weight: 3,
  minPresses: 8,
  cooldown: 5,
  seq: [
    A.open(),
    A.pose("peek", 250),
    A.msg("again", 800),
    A.pose("press", 300),
    A.off(),
    A.pose("hidden", 400),
    A.close()
  ]
}
```

При необходимости добавь строку в `i18n.ru` и `i18n.en`.

## Модели

Список моделей:

```js
const MODELS = ["classic", "industrial", "raccoon"];
```

Тема определяется через `data-model` на `.scene`.

### Как добавить модель

1. Добавить id в `MODELS`.
2. Добавить название в `i18n.ru.modelNames` и `i18n.en.modelNames`.
3. Создать CSS-блок `.scene[data-model="..."]`.
4. При необходимости добавить декоративные assets.

Основная логика не меняется.

# ASSET CONTRACT

## Обязательные графические assets

**Нет.**

V0.9 намеренно использует DOM/CSS для корпуса, крышки, внутренней полости, переключателя и манипулятора. Это техническое решение принято ради стабильной геометрии.

## Необязательные будущие графические assets

### `classic/wood-overlay.webp`

1. Назначение: лёгкая текстура дерева поверх CSS Classic.
2. Размер: 1600×1000 px.
3. Aspect ratio: 8:5.
4. Transparent background: желательно YES.
5. Камера: не применяется; это texture overlay.
6. Положение: бесшовно заполняет поверхность.
7. Обязательно: тонкая натуральная древесная текстура.
8. Нельзя: готовую коробку, тени, перспективу, переключатель.
9. Pivot: center.
10. Использование: `background-image`.
11. Края: tile-friendly.
12. Blend: низкая opacity / `soft-light`.

### `industrial/metal-overlay.webp`

То же, но для матового тёмно-серого промышленного металла.

### `raccoon/raccoon-emblem.webp`

1. Назначение: декоративная эмблема Raccoon Edition.
2. Размер: 512×512.
3. Aspect ratio: 1:1.
4. Transparent: YES.
5. Камера: фронтальная.
6. Объект по центру.
7. Стилизованная голова енота.
8. Без текста и фона.
9. Pivot: center.
10. Использование: декоративный overlay.
11. Не влияет на механику.
12. Края не должны совпадать с другими assets.

## SFX

### `switch-on.wav`
> Один короткий реалистичный звук переключения металлического тумблера в положение ON. Сухой механический click, небольшая металлическая пружина, без ambience, без музыки, 0.1–0.2 секунды.

### `switch-off.wav`
> Один короткий металлический щелчок тумблера в положение OFF. Чуть ниже по тону, чем включение, сухой, физический, без окружения и музыки, 0.1–0.2 секунды.

### `lid-open.wav`
> Короткий звук плавного открытия небольшой деревянной крышки на металлических петлях. Лёгкий деревянный скрип и тихое движение петли, без громкого удара, 0.3–0.6 секунды.

### `lid-close.wav`
> Короткий звук обычного закрытия небольшой деревянной крышки. Мягкий деревянный contact и небольшой механический звук петли. Не хлопок, 0.2–0.4 секунды.

### `servo.wav`
> Тихий короткий звук маленького электрического сервопривода или механического манипулятора. Аккуратное whirr, технологично, но игрушечно, без фона, 0.3–0.6 секунды.

### `impact.wav`
> Маленький точный mechanical tap: металлический кончик манипулятора слегка касается переключателя. Очень коротко, 0.1–0.2 секунды.

### `slam.wav`
> Резкий, но не чрезмерно громкий хлопок деревянной крышки маленькой механической коробки. Небольшой низкий деревянный удар и короткий металлический rattling петли, 0.2–0.4 секунды.

### `weird.wav`
> Очень короткий забавный mechanical glitch для редкой странной реакции коробки: 3–4 быстрых нелепых электронно-механических chirp/servo звука, без речи и музыки, 0.3–0.6 секунды.
