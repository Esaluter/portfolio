# Охотники — История первая: Зверь из старого леса

Небольшая полностью статическая dark-fantasy браузерная игра.

## Запуск

Самый простой вариант: открыть `index.html` в браузере.

Для GitHub Pages:
1. Загрузите все файлы в репозиторий.
2. В Settings → Pages выберите публикацию из нужной ветки.
3. Откройте выданную GitHub Pages ссылку.

Никаких npm, Node.js, backend или внешних библиотек не требуется.

## Управление

- WASD / стрелки — движение
- Space / ЛКМ — атака
- E — взаимодействие
- Esc — пауза

## Прохождение

1. Поговорите со старостой.
2. Найдите три улики.
3. После трёх улик откроется путь к руинам.
4. Пройдите за часовню к логову.
5. Победите Зверя.

Прогресс сохраняется в `localStorage`.
